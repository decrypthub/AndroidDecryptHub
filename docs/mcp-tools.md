Each callback emits a NATIVE_HOOK event with the x0-x8/x18 registers through the bounded live-capture stream. mem (optional, action:hook) copies argument memory on each emitted hit, before the original function runs, into a NATIVE_HOOK_MEM capture paired by seq. Throttled hits are not copied. Empty mem copies nothing.
